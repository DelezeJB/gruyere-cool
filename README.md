# Gruyère d’alpage — Guide gourmand

Site statique minimal dédié au Gruyère d’alpage. Idéal pour un exercice “de A à Z”.

## Déploiement rapide

- **GitHub Pages** : poussez ce dossier dans un dépôt public, puis activez Pages.
- **Netlify** : connectez votre dépôt ou glissez‑déposez le dossier.
- **Cloudflare Pages** : connectez votre dépôt et déployez.

Voir aussi `GUIDE_DEPLOIEMENT.md`.

## Personnalisation

- Remplacez `https://example.com` par votre domaine dans `sitemap.xml` et `index.html`.
- Changez l’adresse dans le formulaire `mailto:` de `index.html`.
